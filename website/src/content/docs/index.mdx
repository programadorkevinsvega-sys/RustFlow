RustFlow busca combinar componentes de interfaz reactivos con una experiencia full-stack en Rust, inspirada en Laravel.

**Estado actual: prototipo pre-1.0; no está listo para producción.** El repositorio ya incluye un runtime reactivo, un modelo tipado de vistas y componentes, un renderer inicial para WASM y un servidor HTTP experimental. Las APIs siguen evolucionando y todavía no existe una experiencia full-stack integrada de extremo a extremo.

## ¿Qué puedes probar hoy?

- **Reactividad en Rust:** señales, efectos, dependencias, batching y scopes de limpieza.
- **Vistas y componentes:** construir árboles tipados y explorar el ciclo de vida del modelo de componentes.
- **Servidor HTTP experimental:** ejecutar un ejemplo con rutas, parámetros de ruta y query, respuestas JSON, middleware global, límites y timeouts.
- **HTML seguro desde vistas:** serializar fragmentos HTML o generar documentos completos con `html_document`; configurar páginas HTML escapadas para estados de error 4xx/5xx.
- **Verificación reproducible:** consultar los tests, incluidos los que envían solicitudes por TCP local, y los checks del repositorio.

## ¿Qué sigue pendiente?

- Un bundle de navegador listo para cargar, actualizaciones DOM dirigidas, renderizado condicional y reconciliación keyed.
- Ejemplos completos de navegador (como contador y todo), pruebas E2E y navegación cliente.
- Hidratación, composición avanzada de layouts y un flujo SSR full-stack completo.
- CLI de RustFlow, scaffolding de proyectos, sesiones, autenticación y persistencia integrada.
- Pruebas de despliegue y transporte para TLS/reverse proxy, concurrencia bajo carga y abortos de cliente.

El routing HTTP y la generación de documentos HTML existen como APIs de prototipo; eso **no** significa que exista ya un framework completo, una plataforma de autenticación/persistencia o una instalación de producción.

## Ruta recomendada

1. [Prueba RustFlow hoy](/getting-started/setup/) desde el repositorio clonado.
2. Revisa [el modelo de componentes](/guides/components/) y sus limitaciones.
3. Ejecuta el [servidor HTTP experimental](/guides/server/) y consulta la [guía técnica del servidor](https://github.com/programadorkevinsvega-sys/RustFlow/blob/main/docs/HTTP_SERVER.md).
4. Consulta [el estado y las fases](/project-status/) antes de decidir si RustFlow cubre tus necesidades.
