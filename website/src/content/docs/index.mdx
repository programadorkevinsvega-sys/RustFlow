RustFlow busca ofrecer componentes de interfaz reactivos y una experiencia full-stack en Rust: rutas, controladores, validación, sesiones, base de datos y herramientas de línea de comandos.

**RustFlow todavía está en desarrollo temprano y no está listo para producción.** Hoy, la parte implementada es la base del runtime reactivo de Rust. El modelo de componentes, el runtime de navegador y el CLI aún no están disponibles.

## ¿Qué puedes hacer hoy?

- **Probar el runtime reactivo:** trabajar con señales, efectos, actualizaciones agrupadas y scopes de limpieza desde Rust.
- **Revisar código y pruebas reales:** las guías se limitan a las APIs que existen en el repositorio.
- **Evaluar el estado del framework:** distinguir capacidades verificadas de las que siguen en diseño o implementación.

## ¿Qué todavía no puedes hacer?

- Crear una aplicación completa con un comando rustflow new.
- Generar componentes con comandos tipo artisan make:component.
- Montar componentes reactivos en el DOM del navegador.
- Usar routing, SSR, autenticación o persistencia como funcionalidades integradas de RustFlow.

Estas capacidades aparecen en fases futuras del [roadmap público](https://github.com/programadorkevinsvega-sys/RustFlow/blob/main/ROADMAP.md). No se presentan como comandos ni APIs disponibles hasta que estén implementadas y probadas.

## Ruta recomendada

1. [Prueba RustFlow hoy](/getting-started/setup/) con la base de Rust que ya existe.
2. [Conoce el runtime reactivo](/concepts/reactivity/) y sus límites.
3. Consulta [el estado y las fases](/project-status/) antes de decidir si RustFlow cubre las necesidades de tu proyecto.
