RustFlow busca combinar una interfaz reactiva con un motor de reactividad propio en Rust y una experiencia full-stack inspirada en herramientas como Laravel.

El framework está en desarrollo. Esta documentación distingue entre capacidades implementadas, trabajo en progreso y objetivos futuros para que los ejemplos no prometan APIs que todavía no existen.

## Una guía que evoluciona con el framework

- **Aprende los conceptos:** comprende las decisiones de diseño y los límites actuales.
- **Sigue ejemplos verificables:** los ejemplos deben corresponder al código disponible en el repositorio.
- **Consulta el estado real:** cada sección indica cuándo una capacidad está planificada, en desarrollo o verificada.
- **Contribuye:** mejora el código y su documentación en el mismo cambio siempre que sea posible.

## Principio de documentación

Una función solo se documenta como disponible cuando su implementación y criterios de aceptación están respaldados por código y pruebas. Los planes se presentan explícitamente como planes.
